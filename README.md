# Portfolio de Khaoula Elhonnya

Site statique (un seul fichier `index.html`), prêt pour GitHub Pages.

## Publier sur GitHub Pages

1. Sur GitHub, crée un dépôt public nommé `TON-PSEUDO.github.io`.
2. Clone-le : `git clone https://github.com/TON-PSEUDO/TON-PSEUDO.github.io.git`
3. Copie dans le dossier cloné : `index.html`, `README.md`, et ton CV dans `assets/cv.pdf`.
4. Publie :
   ```
   git add .
   git commit -m "Ajout du portfolio"
   git push
   ```
5. Sur GitHub : Settings, Pages, Source : branche `main`, dossier `/ (root)`.
6. Le site apparaît sur `https://TON-PSEUDO.github.io` au bout d'une ou deux minutes.

## À personnaliser

- Dans `index.html`, remplace `VOTRE-PSEUDO` (lien GitHub) et `VOTRE-PROFIL` (lien LinkedIn) dans la section Contact.
- Ajoute ton CV en PDF dans `assets/cv.pdf`, sinon le bouton « Télécharger mon CV » mène à une page vide.
- Pour modifier le texte d'un projet, cherche son titre dans `index.html`.
